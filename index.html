Guide｜教师使用说明

How to Use｜如何使用

1. Create Class｜创建班级

在 Manage Class 页面添加班级名称、学生名单、奖品和小组。

2. Check Attendance｜确认出勤

上课前把缺席学生设置为 Absent，工具会自动排除。

3. Choose Template｜选择模板

在班级首页选择热身、词汇复习、阅读课、小组竞赛或课后奖励。

4. Start Class｜开始上课

使用点名、分组、积分、抽奖和倒计时。Class Mode 适合投屏。

5. End Class｜结束课堂

下课后复制课堂报告，查看未参与学生和小组积分。

6. Data｜数据保存

数据只保存在当前设备。换电脑前，请到 Settings 导出备份。

设置内容默认收起，需要时再展开，减少页面信息密度。
